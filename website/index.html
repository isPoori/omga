Get started

Install

Needs Python 3.10+. After install, run omga — the first launch opens a short setup wizard for provider and API key.

Linux & macOS

One-line installer · recommended

bash 
curl -fsSL https://ispoori.github.io/omga/install.sh | bash
alt 
curl -fsSL https://raw.githubusercontent.com/isPoori/omga/main/install.sh | bash

Windows

PowerShell · run as user

powershell 
irm https://raw.githubusercontent.com/isPoori/omga/main/install.ps1 | iex

Package managers

npm or pip · then run omga

npm 
npm i -g omga
pip 
pip install omga-cli

Capabilities

Features

Built for long sessions, real repos, and habits that stick.

  • Memory SQLite sessions with FTS search, USER.md / MEMORY.md, and remember / recall tools.
  • Skills agentskills.io playbooks — bundled defaults plus your own under ~/.config/omga/skills.
  • Surgical edits Prefer precise edit_file over full rewrites, with diffs and approval.
  • Scale Context compression, subagent delegation, and background process polling.
  • Project context Loads AGENTS.md, .omga/rules.md, and related instruction files automatically.
  • Providers OpenRouter, OpenAI, Anthropic, Groq, Ollama, and more — keys in secrets.json only.
