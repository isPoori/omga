# Requesting code review

1. State the **goal** in one sentence.
2. List files touched and why (not a dump of the diff).
3. Call out **risks** (migrations, auth, data loss).
4. Show **proof**: test command + result, or manual check.
5. Note follow-ups you deliberately deferred.
